# FROM MPGI | Events Team Website

Super animated dark neon website for the **FROM MPGI** team.

## Features
- Events are **clickable** → opens full event detail page
- Admin can set an **external Event Page Link** for every event
- Admin can **Add / Edit / Remove** events
- All data lives in `jhat.js` (nothing hardcoded in HTML)
- The line that loads `jhat.js` is **Base64 encoded**
- Admin panel is **hidden** — only opens when you go to `#/321`

## How to open
1. Extract the zip
2. Open `index.html` in browser

## Admin Access

## Files

- `jhat.js` → data backend (events + team)
